# 产品宣传片制作

这是一份产品宣传片工作流技能，供能读取 `SKILL.md` 的助手使用。它约定如何用真实界面做首发、功能介绍或品牌宣传片：先取证，再写脚本和关键帧，配音先行，只做 15–20 秒有声小样，评审后局部迭代，最后扩片验收。

技能正文在 [skills/product-promo-video/SKILL.md](skills/product-promo-video/SKILL.md)。YAML 里的 `name` 是 `product-promo-video`，与所在目录名一致。

## 来源说明

本仓库是对该流程的整理和改写，并补充了授权、真实性与隐私等边界。它不是原作者的官方发布，也不复制来源视频、图片或大段原文。教程中的曝光成绩、模型偏好和工具组合未经本仓库独立验证；百万曝光等传播效果未验证，不能当成已达成的结果。不要把本文理解成“已观看来源视频”或“已验证来源工程”。

本仓库未选择许可证。这里的说明只覆盖本仓库对流程的整理方式，不用某种开源许可证去授权来源教程或其素材。

## 工作流

按下面的顺序做。每一步的停止条件和检查项以技能正文为准。

1. **真实界面。** 用同一组可公开的演示数据，取操作前、操作中、结果三张真实界面。没有运行权限时使用用户提供的真实录屏。不绘制假界面冒充实测，不改生产数据。
2. **三栏脚本。** 写“旁白—屏幕短字—画面动作”，并配三张静态关键帧。先不定死全片秒数。
3. **配音先行。** 显示稿和口播稿分开。试听后锁定声线，按自然段测量实际音长，再据此对齐画面。没有可靠时间戳就不标称精确。
4. **15–20 秒小样。** 按实测音长做可播放有声小样，默认先不加音乐。检查静音是否连续、声画是否对齐、手机尺寸是否可读。不凭截图宣布视频合格。
5. **局部迭代。** 把反馈写成具体秒数、问题和预期。锁住已经满意的部分，每次只改最影响观看的一处，并另存版本。
6. **扩片验收。** 小样通过后，再加痛点开场、另外一两个核心场景和行动提示。新增旁白仍先出音频。交付前核查事实、授权、隐私、可读性、同步，以及黑帧、抖动、畸变、屏幕漂移和遮罩穿帮。不自动发布。

品牌形象片不硬塞功能操作，走技能正文里的品牌片分支。

| 阶段 | 技能正文 |
| --- | --- |
| 输入、授权与真实性 | 第 1 节 |
| 真实界面 | 第 2 节 |
| 三栏脚本与关键帧 | 第 3 节 |
| 配音先行 | 第 4 节 |
| 15–20 秒小样 | 第 5 节 |
| 局部迭代与扩片 | 第 6 节 |
| 扩片验收与停止 | 「交付与停止条件」 |

来源不足、授权不清、工具不可用或预算未批准时，停在受影响的那一步，并说明缺什么。脚本或静帧若不受该缺口影响，仍可以先完成。

## 手动安装

安装位置因宿主而异。请按该宿主自己的文档，把技能放到它指定的技能目录。本仓库没有安装器，也没有在任何宿主上验证过安装命令，所以这里不给出安装命令。

手动操作时，复制整个 `skills/product-promo-video` 目录，使目标位置的这一层目录名仍是 `product-promo-video`，并且其中直接包含 `SKILL.md`。宿主若要求别的目录名、仓库根路径或额外注册步骤，以其文档为准。

技能末尾的「可选适配：Grok Bot」只在宿主就是 Grok Bot 时阅读。通用步骤不依赖该节里的内部能力。

## 开始前准备这些输入

已有的信息直接用，只补会影响结果的缺口。

- 产品材料、核心价值、受众、渠道、画幅、语言、目标时长、行动目标
- 一个核心功能，以及一条连续操作路径；品牌片则改为品牌识别和情绪目标
- 品牌资产，以及素材、音乐、字体、Logo、肖像的使用权
- 可公开的演示数据；需要标明的示例数据
- 参考片（只借鉴叙事和构图）
- 已有的真实录屏或授权测试环境
- 当前真正可用的工具和预算

同时确认：不编造功能、客户案例或经营结果；测试不碰生产数据；成片发布前去掉隐私、令牌和通知内容。

## 调用示例

下面两段可以直接交给助手。示例里的产品是虚构的，使用时换成你的产品、路径和时长。助手需要能读到本技能；如何把技能附到对话里，按宿主文档操作。

功能片，先停在小样：

```text
请使用 product-promo-video 技能，为虚构的本地笔记应用「纸页」做一条功能宣传片。假定我已经提供授权测试环境和一组可公开的演示笔记。先核对输入和素材授权是否够用。够用的话，只选「新建一条笔记并搜索到它」这一条路径，用真实界面取证，写出旁白、屏幕短字、画面动作三栏脚本和三张关键帧。配音先行，只做 15–20 秒有声小样。不要铺全片，不要安装新工具，不要自动发布。小样交给我评审后，再按我指出的秒数局部修改。
```

品牌片：

```text
请使用 product-promo-video 技能里的品牌片分支，为虚构品牌「纸页」做品牌形象小样。不要硬塞功能操作。先核对 Logo、字体和音乐的使用权。可以先做品牌几何和材质的静帧；若做动态，只做 5–8 秒空间展开小样，并检查遮罩、重影和归位。视频生成和渲染工具都先确认是否已经可用，不要默认安装。完成小样后停下来等我验收。
```

## 工具现状

Remotion、文本转语音和视频生成服务都没有在本仓库打通，也没有安装。这里没有渲染脚本、工程模板或一键出片程序。正文里出现的 Codex、Claude、MiniMax、Seedance、Remotion 等，只是来源教程中的工具示例。

要用其中任何一个，先确认它在当前环境里确实可用，再单独确认登录、费用和授权。付费、安装软件，以及把成片发到其他平台，都不包含在本仓库里，技能也要求这些动作另经当次明确授权。
